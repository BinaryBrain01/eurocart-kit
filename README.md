# EuroCart kit

Starter material for an Elephant Carpaccio workshop built around **EuroCart**: an order calculator
for a web shop selling to six European countries (base price → VAT → currency → shipping → discount → total).

Using this material is optional. Teams are free to pick any language, framework or tooling.

| Directory | What |
|---|---|
| [`skeleton-spring/`](skeleton-spring/) | Spring Boot 4.1 / Java 21 skeleton: product catalogue (50 products), in-memory cart, subtotal excl. VAT, static HTML front-end. |
